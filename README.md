# Brownfield Opportunities

Static dashboard of large EPA Superfund sites — map and table view with site-level detail. Designed to live on GitHub Pages and refresh via a one-command CLI.

**Live:** https://pranava0x0.github.io/brownfield-opportunities/

## What's in v1

- **Top 100 Superfund sites by acreage** (NPL listed, proposed, deleted, and partial — all included).
- **Map view (default)** with Canvas-rendered markers on CARTO dark tiles; **Table view** with sortable columns.
- **Mobile-friendly:** detail panel becomes a bottom sheet on phones; tap targets sized for touch; tiles preconnected and `sites.json` preloaded for fast first paint.
- **Side panel** on click: name, NPL status, acreage, EPA ID, full address, coordinates, link to EPA site profile.
- **Source:** [EPA NPL Superfund Site Boundaries (Public)](https://hub.arcgis.com/datasets/EPA::npl-superfund-site-boundaries-epa-public-2022/about) ArcGIS FeatureServer.

Many fields you'd want — current owner, historical owners, encumbrances, infrastructure proximity, and the full Brownfields/ACRES universe — are deferred. See [`backlog.md`](backlog.md) for the data-center-opportunity pivot and the data sources that would feed it.

## Refresh the data

```bash
pip install -r requirements.txt
python refresh.py                 # default: top 100 by acreage
python refresh.py --limit 250     # different size
python refresh.py --no-cache      # force fresh fetch
python refresh.py --dry-run       # use only cached responses
```

Output: `docs/data/sites.json` — committed to git, served statically by Pages.

The script is idempotent: re-runs hit a local cache (`data/cache/`) until you pass `--no-cache`.

## Local preview

```bash
python3 docs/serve.py 8765
# → http://127.0.0.1:8765
```

(`docs/serve.py` is a 5-line wrapper around `http.server`. Used only for local dev.)

## Deploy

Two GitHub Actions workflows in `.github/workflows/`:

- **`deploy.yml`** — every push to `main` publishes `docs/` to GitHub Pages.
- **`refresh.yml`** — weekly cron (Mon 07:00 UTC) re-runs `refresh.py` and commits the JSON if it changed. Manually triggerable from the Actions tab with a `--limit` override.

To enable Pages on a fresh repo: **Settings → Pages → Source: GitHub Actions**.
