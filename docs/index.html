    How to read the evidence

    Use changes the next checks: data centers need firm power and carrier service; generation needs an export study; manufacturing needs process utilities and freight access. The mapped facts stay the same.

    Compare grid, fiber, water, land and logistics separately. Sites appear alphabetically. Confidence describes the support for a finding, not whether a site is suitable. Unknown means the question is unassessed. A mapped feature does not establish service, capacity, ownership or permission to use it.

    Open a site for its sources and remaining checks. See Data & methods for coverage and limitations.

    Nuclear reactor siting — 14 military installations

    Fourteen curated military installations, with separate infrastructure findings and confidence. Select a reactor class, then open a site for sources. Land availability, grid capacity and usable cooling water remain unverified.

    Sources and limits of this screen

    These installations are a curated population, separate from the shared site database. Grid distances use selected cleanup-site reference points; they are not distances from a proposed construction parcel. Reported installation area does not establish available land.

    Water-source descriptions are analyst research. River flow and historical facility demand do not establish spare supply, drought reliability or a project allocation. Fiber ratings without site-specific citations are shown as unknown. Reactor classes do not resolve those evidence gaps.

    Janus program interest is not a reactor award or a large-reactor approval. Inspect project-specific sources and dates in each site. Read the data methods.
